# Cybersecurity Home Lab

**Offensive Security | SIEM Monitoring | Incident Response**

## Overview

A hands-on cybersecurity laboratory built using Oracle VirtualBox to practice penetration testing, threat detection, security event analysis, and incident response.

The project simulates controlled attacks from Kali Linux against an Ubuntu Server while using Wazuh SIEM to monitor and investigate suspicious activity.
